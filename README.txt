모모네 쉼터초원 🌿🐰 | 무료 웹앱 v3 (손글씨·캘리그라피 제거)

포함 기능
  • 감정 선택 및 모모래빗 응원
  • 5가지 마음일기 질문 + 선택적 말씀 묵상 기록
  • 매일 바뀌는 성경 구절 주소(31개 순환), 대한성서공회 개역개정 공식 링크, 묵상 질문과 창작 기도문
  • 1분 호흡 휴식
  • 마음 달력, 12월의 나 돌아보기, JSON 백업·복원, TXT 내보내기
  • 로그인/광고/유료 결제 없음

변경된 점
  • 캘리그라피 및 손글씨 마음카드 5종, 카드 저장·공유 UI를 완전히 제거했습니다.
  • 일반 버튼·앱 화면·토끼 캐릭터는 그대로 유지했습니다.

GitHub Pages 설치 방법
  1. 이 ZIP을 풀어 index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png를 GitHub 저장소의 최상위에 업로드합니다.
  2. Settings → Pages → Deploy from a branch → main / (root) → Save.
  3. 생성된 HTTPS 주소를 모바일 브라우저에서 열고 홈 화면에 추가합니다.
  4. 기존 앱 URL을 그대로 사용하면 이전 브라우저 기록이 유지되도록 로컬 저장 키를 바꾸지 않았습니다. 캐시 때문에 구버전이 보이면 새로고침 후 다시 접속하세요.

기록 안전 안내
  • 반드시 기존 앱에서 JSON으로 백업한 후 교체하세요.
  • 새로운 웹주소·새 브라우저·별도 홈 화면 앱은 저장소가 달라 기존 일기가 자동으로 옮겨지지 않을 수 있습니다. 새 앱의 12월의 나 → 백업 불러오기를 이용하세요.
  • 저장 데이터는 해당 브라우저에만 있고 암호화되지 않은 백업 JSON은 민감한 개인 일기를 포함할 수 있으므로 안전하게 보관하세요.

성경 본문 저작권
  • 개역개정 본문을 앱 내부에 복제하지 않고 대한성서공회 공식 사이트 링크로 연결합니다. 인터넷 연결이 필요합니다.

단일 HTML 체험 파일은 GitHub 배포 없이 다운로드해 확인할 때 사용합니다. 파일 앱에서 직접 열면 브라우저 보안 제한으로 일부 기능이 동작하지 않을 수 있습니다.
