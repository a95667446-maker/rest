모모네 쉼터초원 🐰🌿 | 무료 웹앱 v1.1

1. GitHub Pages 업로드
  ZIP을 압축 해제하고 index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png를 모두 새 저장소의 최상위(root)에 업로드합니다.
  Settings → Pages → Deploy from a branch → main / (root) → Save.
  iPhone Safari: 웹앱 주소 열기 → 공유 → 홈 화면에 추가
  Android Chrome: 웹앱 주소 열기 → 메뉴 → 홈 화면에 추가 또는 앱 설치

2. 포함 기능 (모두 무료)
  오늘의 감정/모모래빗 응원, 5가지 질문의 마음일기, 손글씨 느낌 마음카드 5종 저장·공유, 1분 호흡, 기록 달력, 12월의 나 회고, JSON 백업·복원, TXT 내보내기
  토끼 그림은 테스트용 도안입니다. 추후 원본 모모래빗 캐릭터로 교체할 수 있습니다.

3. 이전 데이터
  기존 마음쉼표와 같은 GitHub Pages 주소(동일 origin)에서 업로드 교체하면, 기존 브라우저 기록을 유지하도록 localStorage 키를 그대로 두었습니다.
  * 다른 저장소나 다른 URL로 옮긴 경우 데이터가 자동 이전되지는 않습니다. 기존 앱에서 JSON 백업 파일을 저장한 뒤 새 앱의 '12월의 나' → '백업 불러오기'를 이용하세요.
  * 업로드 전에 기존 앱 기록을 꼭 백업하세요. 홈 화면에 따로 추가한 앱에서는 브라우저 저장 공간이 분리될 수 있으므로 반드시 기록을 확인하세요.

4. 개인정보
  회원가입, 광고, 결제가 없고 입력 기록은 서버에 전송되지 않습니다.
  브라우저 localStorage가 삭제되면 기록이 사라질 수 있습니다. 정기적으로 백업하세요.
  JSON 백업은 암호화되지 않은 개인 일기이므로 안전한 곳에 보관하세요.

5. 기타
  HTML 단일 파일은 빠른 미리보기용입니다. 아이폰 파일 앱에서 열면 자바스크립트 실행이 제한될 수 있어 GitHub Pages URL 사용을 권합니다.
  쉼터초원은 일상의 자기성찰 도구이지 전문적인 치료 서비스를 대체하지 않습니다.
